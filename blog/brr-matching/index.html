Flutter · 프로젝트 기록

부르릉에서 두 가지 매칭 방식을 연결한 과정

Flutter 화면에서 빠른 매칭과 예약 매칭을 구분하고 서버에 신청을 보내는 흐름을 정리했습니다.

부르릉은 부산대생이 비슷한 목적지로 이동할 때 택시를 함께 탈 수 있도록 만든 앱입니다. 바로 출발할 동승자를 찾는 빠른 매칭과 특정 시간에 동승자를 모집하는 예약 매칭을 제공합니다.

매칭 목록을 보여주는 방법

두 종류의 매칭을 한 목록 화면에서 전환할 수 있도록 만들었습니다. 예약 매칭 탭에서는 서버에서 받은 데이터를 목록에 표시해 사용자가 항목을 찾아볼 수 있게 했습니다.

신청 전에 확인한 정보

빠른 매칭을 시작하려면 출발지, 목적지, 최소 탑승 인원이 필요합니다. 필수 입력값을 확인한 후 매칭 API에 요청을 보내도록 화면과 서버를 연결했습니다. 매칭 목록을 조회하는 기능과 새 매칭을 신청하는 기능은 서로 다른 API 요청으로 처리됩니다.
